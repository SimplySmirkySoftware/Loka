# v0.0.7 Classic release archive allowlist (0.0.5 shape plus the owner's
# 2026-10-11 decisions 3 and 5): every application ships its MacBinary .bin and
# an 800 KiB HFS .dsk beside it, so it can be mounted in an emulator or copied
# to a floppy without a MacBinary decoder. Plain applications use Retro68's own
# image; ScrapbookUI (68K, PPC) and SmirkyCard (68K) use the images
# scripts/release/classic-disks.py builds with ASSETS.LRP or MAIN.JS beside the
# application (#1250). SimpleText is new in both architectures (#1131, #1254).
# LazyList and SmirkBench are measurement benches and are not shipped.
# SmirkyCard stays experimental. It ships for 68K and PPC (owner decision 8,
# 2026-10-12) beside the card scripts in example/SmirkyCard/disk-scripts.txt
# (MAIN.JS links to MINES.JS, VIEWER.JS and, new in v0.0.7, LAPTOP.JS; the
# SmirkyTracker pictures travel inside the .dsk); each disk carries the same scripts
# (#1260). The PPC disk is a 2 MiB image, not a floppy. The PPC configure needs
# -DLOKA_BUILD_SMIRKYCARD=ON like the 68K one.
